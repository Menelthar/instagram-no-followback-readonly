# SUBIR ESTE PROYECTO A GITHUB

Repositorio objetivo:
https://github.com/Menelthar/instagram-no-followback-readonly

1. Entra a GitHub con la cuenta Menelthar.
2. Pulsa el botón "+" de la barra superior.
3. Selecciona "New repository".
4. Nombre: instagram-no-followback-readonly
5. Descripción:
   Read-only Instagram scanner that identifies accounts you follow that do not follow you back. No passwords, no external uploads, no automated unfollows.
6. Visibilidad: Public.
7. NO marques "Add a README", "Add .gitignore" ni licencia.
8. Pulsa "Create repository".
9. En la página del repositorio vacío, pulsa "uploading an existing file".
10. Arrastra TODO el contenido de la carpeta descomprimida, no la carpeta contenedora.
11. Escribe el commit:
    Initial public release v1.0.0
12. Pulsa "Commit changes".

Después configura:

A. GitHub Pages
- Settings > Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

B. Descripción y temas
- En la portada del repositorio, abre el engrane de About.
- Website: https://menelthar.github.io/instagram-no-followback-readonly/
- Topics:
  instagram, instagram-followers, instagram-unfollowers, privacy, read-only, javascript, browser-script, open-source

C. Seguridad
- Settings > Security > Code security and analysis
- Activa Private vulnerability reporting, si aparece disponible.

D. Validación
- Abre la pestaña Actions.
- Confirma que el workflow "Validate" termine en verde.

Sitio esperado:
https://menelthar.github.io/instagram-no-followback-readonly/
