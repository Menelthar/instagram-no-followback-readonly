# Support

## Before opening an issue

1. Read the [Spanish troubleshooting guide](docs/TROUBLESHOOTING_ES.md) or [English troubleshooting guide](docs/TROUBLESHOOTING_EN.md).
2. Confirm you are using the latest unmodified source from `main`.
3. Run the scan only on `https://www.instagram.com/`.
4. Remove all private account data from logs and screenshots.

## Bug reports

Use the repository bug-report template and provide:

- Browser name and version.
- Script version.
- Exact error message.
- Reproduction steps.
- Sanitized diagnostic output.

## Security reports

Do not disclose vulnerabilities or account data in a public issue. Follow [SECURITY.md](SECURITY.md).

## Scope

Support is provided for:

- Script compatibility.
- Read-only scanning.
- Result presentation and export.
- Documentation and accessibility.

The following are out of scope:

- Automated follow or unfollow.
- Bypassing Instagram limits or warnings.
- Account recovery.
- Password, cookie, or token handling.
- Third-party modified builds.
