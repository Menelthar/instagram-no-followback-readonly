# Usage guide — version 1.1.0

1. Sign in at `https://www.instagram.com/` using a desktop browser.
2. Open the project website and review the source.
3. Copy the script.
4. Open the browser console and paste it.
5. Click **Start scan**.
6. Review the integrity panel when it finishes.

`Complete` means no discrepancy was detected. `Review` means the scanner found a count mismatch, duplicate, invalid record, uncertain relationship, or remote count change.

Internal IDs and profile-picture URLs are excluded from exports by default. **Copy diagnostic** creates a safe technical report without usernames or user IDs.
