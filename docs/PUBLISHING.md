# Publishing the repository

## Create the repository

1. Sign in to GitHub.
2. Create a new repository named `instagram-no-followback-readonly`.
3. Set visibility to **Public**.
4. Do not initialize it with a README, license or `.gitignore` if uploading this prepared project.
5. Upload the complete contents of this folder.
6. Commit directly to `main`.

Repository target:

`https://github.com/Menelthar/instagram-no-followback-readonly`

## Enable GitHub Pages

1. Open **Settings** in the repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main`.
5. Select folder `/ (root)`.
6. Save.

Expected site:

`https://menelthar.github.io/instagram-no-followback-readonly/`
